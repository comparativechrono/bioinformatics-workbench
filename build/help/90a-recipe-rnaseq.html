RNA-seq: reads to differential expression

Two halves of an RNA-seq analysis. First, map real RNA-seq reads with HISAT2 and see reads split across an intron. Then, from the gene counts of a published experiment, find the genes that a drug switches on or off – with DESeq2, and with edgeR for comparison.

The button writes the steps below into a new R notebook in ~/notebooks; the terminal's steps become %%bash cells. Run the cells from the top.

1. A folder for the work

setwd() makes it the folder of the notebook's R code and of its %%bash cells.

dir.create("~/recipe-rnaseq", showWarnings = FALSE)
setwd("~/recipe-rnaseq")

2. Map RNA-seq reads with HISAT2

256 pairs of reads from yeast RNA (study GSE110004), and chromosome I of the yeast genome as the reference. hisat2-build indexes the reference once; hisat2 maps the reads and reports how many it placed.

hisat2-build /data/examples/rnaseq/yeast_chrI.fa yeast_chrI > /dev/null 2>&1
hisat2 -x yeast_chrI -1 /data/examples/rnaseq/SRR6357070_1.fastq -2 /data/examples/rnaseq/SRR6357070_2.fastq \
       2> hisat2.log | samtools sort -o rnaseq.bam -
samtools index rnaseq.bam
cat hisat2.log

3. Reads across an intron

A read from a spliced RNA can start in one exon and end in the next. HISAT2 splits it: an N in the CIGAR string is the intron that the read skips. 80M366N21M means 80 bases on the genome, 366 skipped, then 21 more. How many reads skip an intron, and how long are the introns they skip?

samtools view rnaseq.bam | awk '$6 ~ /N/' | wc -l
samtools view rnaseq.bam | awk '$6 ~ /N/ {match($6, /[0-9]+N/); print substr($6, RSTART, RLENGTH)}' | sort | uniq -c | sort -rn

Most of them skip the same 366 bases: the intron of EFB1 (YAL003W), a yeast gene at I:142,174–143,160, whose intron holds a small nucleolar RNA gene (snR18). – the reads are drawn with a thin line across the intron, under the gene's exons.

4. The counts of a whole experiment

Differential expression starts from a table: how many reads each gene got in each sample. For whole genomes such tables are made on a server (featureCounts, HTSeq or salmon); this one is from the Bioconductor package airway: human airway smooth muscle cells, four cell lines (cell), each untreated and treated with the steroid dexamethasone (dex) – Himes et al., PLoS ONE 2014.

counts <- as.matrix(read.delim("/data/examples/rnaseq/airway_counts.tsv", row.names = 1, check.names = FALSE))
samples <- read.delim("/data/examples/rnaseq/airway_samples.tsv", row.names = 1)
samples <- samples[colnames(counts), ]
samples$cell <- factor(samples$cell)
samples$dex <- factor(samples$dex, levels = c("untrt", "trt"))
dim(counts)
samples[, c("cell", "dex")]
colSums(counts) / 1e6   # reads per sample, in millions

5. DESeq2

The design ~ cell + dex compares treated with untreated cells of the same cell line. Genes with almost no reads are left out first. The first library(DESeq2) downloads about 40 packages – give it a minute; DESeq() takes about as long.

library(DESeq2)
dds <- DESeqDataSetFromMatrix(countData = counts, colData = samples, design = ~ cell + dex)
dds <- dds[rowSums(counts(dds)) >= 10, ]
dds <- DESeq(dds)
res <- results(dds, contrast = c("dex", "trt", "untrt"), alpha = 0.05)
summary(res)

DESeq() normalises for the depth of each sample (size factors), estimates how much each gene varies between replicates (dispersion), and tests every gene. padj is the p-value adjusted for testing thousands of genes: a cut-off of 0.05 keeps the false discoveries near 5%.

6. The genes that changed most

top <- as.data.frame(res[order(res$padj), ])
head(top[, c("baseMean", "log2FoldChange", "padj")], 10)
write.csv(top, "deseq2_dex_vs_untreated.csv")

A log2 fold change of 2 is four times as much RNA in treated cells; −2 a quarter. Third in the list is DUSP1 (ENSG00000120129), a well-known target of steroids such as dexamethasone. Search an ID in the Databases tab (Ensembl card) to see the gene's name.

7. Plots

The MA plot shows every gene: its mean count and its fold change, the significant ones in colour. The PCA plot of variance-stabilised counts shows which samples resemble each other – by treatment first, then by cell line.

plotMA(res, ylim = c(-5, 5))
vsd <- vst(dds, blind = FALSE)
plotPCA(vsd, intgroup = c("dex", "cell"))
plotCounts(dds, gene = "ENSG00000120129", intgroup = c("dex", "cell"))

8. The same with edgeR

edgeR models the counts in a similar way, and tests them with quasi-likelihood F-tests. How many of DESeq2's genes does it find too? (edgeR loads limma, whose plotMA hides DESeq2's: after this step, write DESeq2::plotMA(res).)

library(edgeR)
y <- DGEList(counts = counts, samples = samples)
keep <- filterByExpr(y, group = samples$dex)
y <- normLibSizes(y[keep, , keep.lib.sizes = FALSE])
design <- model.matrix(~ cell + dex, data = samples)
y <- estimateDisp(y, design)
fit <- glmQLFit(y, design)
qlf <- glmQLFTest(fit, coef = "dextrt")
summary(decideTests(qlf))

edger_genes <- rownames(topTags(qlf, n = Inf, p.value = 0.05))
deseq2_genes <- rownames(top)[which(top$padj < 0.05)]
c(DESeq2 = length(deseq2_genes), edgeR = length(edger_genes), both = length(intersect(deseq2_genes, edger_genes)))
Good to know

DESeq2 and edgeR need raw counts – whole numbers, not normalised values – and biological replicates. In the browser they run as on a computer: locfit, a package they need, was built for the workbench, and a check against R on Linux gave the same results. Download the notebook to run it in RStudio or Jupyter: BiocManager::install(c("DESeq2", "edgeR")) there.
