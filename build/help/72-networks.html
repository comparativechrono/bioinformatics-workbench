The Networks tab

Networks of interacting genes and proteins – or of anything else with links between things: open them, colour and size them with your own data, look for their hubs and clusters, and save pictures and files of them. The tab works like the desktop program Cytoscape, and reads and writes its files; it is built on Cytoscape.js.

The parts of the tab

  • The toolbar: the network you are looking at (click it to switch to another, rename, duplicate or close it), then Open, Data, Layout, Select, Analyse and Save, a box to find nodes, undo and redo.
  • The network, with the number of nodes and edges at the top left, the legend at the bottom left (− folds it away) and, at the bottom right, zoom, fit and a button that hides the panels to give the network the whole tab.
  • The side panel: Style (colours, sizes, shapes, labels), Select (filters), Results (of the analyses) and Details (of what is selected).
  • The tables underneath: one row for each node, or each edge, with all their columns. Drag the bar above them to make them taller.

What goes to the services

STRING, IntAct, NDEx and g:Profiler get the names you send them – gene names, accessions, search words – and nothing else: your tables stay in the browser. Never send personal or patient data. STRING's and IntAct's data are CC BY 4.0: cite them (below) when you publish a network made from them.

Find your way

  • Drag the background to move; the mouse wheel (or a pinch) zooms; F or the fit button shows the whole network.
  • Click a node or an edge to select it; Shift+click adds to the selection; Shift+drag draws a box around several. Drag a node to move it. A double-click zooms in on a node and its neighbours.
  • Right-click a node: its neighbours, its interactors from STRING, its UniProt entry, its AlphaFold structure in the 3D viewer, its gene in the Genome browser (human, hg38); right-click the background to add a node there.
  • Find nodes (the box in the toolbar) marks the nodes whose names contain what you type – several names, separated by spaces, at once; Enter selects them and zooms to them.
  • Delete deletes what is selected; Ctrl+Z undoes (deletions, layouts, imports, analyses), Ctrl+Shift+Z redoes; Esc selects nothing. (The keys work once you have clicked the network.)

The tables

The node table has a row for each node and a column for each attribute: its name, the columns of the file it came from, those of tables you imported, and those the analyses add. The edge table does the same for edges, and Network describes the network as a whole.

  • Click a column's name to sort by it; click a row to select its node (or edge) and go to it. only selected shows the rows of what is selected; the box filters the rows by any text.
  • Double-click a cell to change it. The ⋯ of a column: colour or size the nodes by it, a histogram, select by its values, rename it, delete it.
  • Save writes the table as a CSV file into your files.

Your data on the network

Data → Import a table of values onto the nodes… joins a table to the nodes: each row whose name (or ID) matches a node adds its columns to that node. The tab finds the pair of columns that match best – gene names with gene names, Ensembl IDs with Ensembl IDs – and says how many nodes found a row. Networks from STRING keep what you typed in the column query, so Ensembl IDs from DESeq2 match there.

Style

Every look of a node or an edge – fill colour, size, shape, label, border, opacity; edge colour, width, line, arrow – is the same for all, or mapped from a column, in the Style panel:

  • Continuous (a column of numbers): a range of colours or sizes. For fold changes, the blue – grey – red colours (blue down, grey unchanged, red up) with 0 in the middle; for p-values, −log₁₀ so that the smallest p-values give the largest nodes. 95% of them sets the ends of the scale so that a few extreme values do not wash the others out (those get the colour of the end, ≥ in the legend).
  • Discrete (any column): a colour, shape or size for each value – clusters, kinds of molecule, the two clubs of the karate club. The first eight values get eight colours chosen to be told apart by colour-blind readers too; more values are grey unless you choose a colour for them.
  • Label: any column, or none.
  • Chart: a ring of slices on each node, one for each column ticked, coloured by its value – the fold changes of several experiments on one network.

The ready-made styles set several at once: Plain, Confidence (edges wider for higher STRING or IntAct scores), Expression (fill by the fold change, size by the adjusted p-value), Clusters (a colour for each cluster) and Degree (size and colour by the number of edges). The legend follows the mappings; it is drawn in saved pictures too.

Layouts

LayoutFor
Force-directed (fCoSE)The usual first choice: nodes repel each other, edges pull them together, so connected groups come together. Separate pieces are packed side by side.
… strong edges shorterThe same, with edges of high score (STRING, IntAct) shorter.
Circle, GridEvery node visible and in order – small networks, or to start editing.

Hierarchical (dagre)Directed networks – signalling, regulation, pathways – in layers from top to bottom.

Spring-embedded (CoSE)Cytoscape.js's older force-directed layout.

A layout of the selected nodes only rearranges a part and leaves the rest. Layouts can be undone.

Select, edit, combine

  • Select: all, none, the inverse, the neighbours of what is selected, the edges between the selected nodes, nodes without edges, the shortest path between two selected nodes – and, in the Select panel, by the values of columns (padj < 0.01, |log2FoldChange| ≥ 2, a name that contains a word …), with several conditions.
  • What is selected becomes a new network (with the edges between its nodes), can be hidden, or deleted.
  • Data: add a node, an edge between two selected nodes, the interactors of the selected nodes from STRING, STRING's interactions between the nodes of a network that has none; merge two networks (union, intersection, difference – nodes matched by name or another column); treat the edges as directed (arrows).

Analyse

Analyse computes the statistics of the network (degree, betweenness, closeness, clustering coefficient …), ranks its hubs, finds clusters (MCODE, MCL, Louvain), connected components and k-cores, the shortest path between two nodes, and the functions and pathways its genes share. Each result appears in the Results panel and adds columns to the node table. What each one means, and how it was checked: Network analysis.

To a notebookAdds code to the open notebook that reads the network: for Python, the network is saved as GraphML in ~/networks and read with networkx; for R, its node and edge tables are saved as CSV files there and made into a network with igraph.

The networks that are open are kept in this browser, in ~/.networks/session.json: they are there again when you come back. To keep a network for good, or take it elsewhere, save it as a file.

# a network made in Python, opened in the Networks tab
