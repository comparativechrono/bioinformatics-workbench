The workbench

Notebooks in Python and R, a Linux terminal with real bioinformatics programs, Galaxy, database searches, a 3D protein viewer, a genome browser and an AI assistant – all in this browser tab. Pick a tab on the right; this pane explains each one.

Everything runs in your browser

The programs, Python and R run inside this web page, on your computer. Your files are kept in this browser (not on a server), so they are there next time on this computer and browser – download what you want to keep (every notebook downloads as .ipynb). Search the help with the box above, or press Ctrl+\ to hide it and give the workbench the whole window.
