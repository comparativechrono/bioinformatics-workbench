The layout and the keys

The help on the left, the workbench on the right. The help can go, and the workbench can fill the screen.

The help pane

  • Hide it with the button at its top, or Ctrl+\ (⌘+\ on a Mac). The same keys (or the button at the top left) bring it back.
  • Make it wider or narrower by dragging the line between the two panes.
  • Search with the box at its top: it finds words in every page, including the names of programs and options.
  • Under the search box, Help for the … tab opens the page of the tab you are in. Every tab also has a button of its own.

Full screen (top right) gives the workbench the whole screen and hides the help; Esc leaves it.

When the right pane is narrow, the tabs show only their icons; hover over one to see its name. The arrow keys move between tabs when one has the keyboard focus.

On a small screen

On a phone or a narrow window the workbench comes first and the help opens over it (the button at the top left); tap outside it, or press Esc, to close it. The notebook and the terminal work on a tablet; for real work a laptop or desktop is much easier.

Keys

The keys of each tab are in Keyboard shortcuts. The ones you will use most:

Shift+Enterrun a notebook cell and go to the next
Ctrl+Ssave – a file you edit in the Files tab is saved only then (or with Save); notebooks also save themselves
↑ ↓ in the terminalearlier commands
Tab in the terminalcomplete a file or command name
Ctrl+C in the terminalstop: the program that is running finishes, the rest of the command is skipped; press it again to stop the program itself
Ctrl+\hide or show the help
