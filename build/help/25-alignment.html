Alignments and trees

Pairwise alignment (needleman_wunsch, smith_waterman), multiple alignment (kalign, muscle), trees (FastTree), and long DNA alignments (lastz).

The examples work in a folder of your own:

Two sequences

needleman_wunsch --printscores GATTACA GCATGCT
smith_waterman --printseq ACACACTA AGCACACA

needleman_wunsch aligns two sequences from end to end (global); smith_waterman finds the best-matching parts (local) and lists every good hit. The scores they use unless told otherwise differ: needleman_wunsch --match 1 --mismatch -2 --gapopen -4 --gapextend -1, smith_waterman --match 2 --mismatch -2 --gapopen -2 --gapextend -1. For proteins --scoring BLOSUM62 (also PAM30, PAM70, BLOSUM80). With --file pairs.fasta they align the sequences of a file two at a time.

needleman_wunsch --scoring BLOSUM62 --gapopen -10 --gapextend -1 --printscores \
  MVLSPADKTNVKAAWGKVGAHAGEYGAEALERMFLSFPTTKTYFPHF MVHLTPEEKSAVTALWGKVNVDEVGGEALGRLLVVYPWTQRFFESF

lcs SEQUENCE (also from seq-align) lists the substrings that occur twice in a sequence, longest first.

Multiple alignment

kalign -i /data/examples/sequences/myoglobins.fasta -o myoglobins.afa
muscle -in /data/examples/sequences/myoglobins.fasta -out myoglobins_muscle.afa
open myoglobins.afa

Both write aligned FASTA: every sequence has the same length, with - for gaps. The Files tab shows an alignment in colour, column by column. Clustal format: kalign -f clu, muscle -clw. Give kalign its output file with -o: this version also prints its banner on the standard output, so kalign … > file would put the banner into the file.

A tree

fasttree myoglobins.afa > myoglobins.nwk
cat myoglobins.nwk
open myoglobins.nwk

FastTree builds an approximately-maximum-likelihood tree (JTT+CAT for proteins; -nt for DNA, with -gtr for the GTR model). The numbers before the branch lengths are local support values (0–1). The Files tab draws a .nwk file as a tree; in R, ape::read.tree() reads it, in Python Bio.Phylo.

FastTree -nt -gtr /data/examples/sequences/tRNA-Thr.afa > trna.nwk 2> /dev/null && cat trna.nwk

Long DNA: lastz

lastz aligns long DNA sequences – a region against a chromosome, two related genomes. [multiple] after the target file means it has more than one sequence; quote it, because [ ] mean something to the shell.

samtools faidx /data/examples/reads/reference.fa human_CYP2C19:1000-3000 > piece.fa
lastz '/data/examples/reads/reference.fa[multiple]' piece.fa --format=general | head -4

Formats: --format=general (a table), maf, sam, axt; --notransition --step=20 make it faster on big sequences.

Alignments and trees are also tools in Galaxy (Kalign, MUSCLE, FastTree), and BLAST searches run at EBI from the Databases tab.
