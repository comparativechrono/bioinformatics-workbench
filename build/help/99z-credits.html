Data and services

  • The example reads: the 1000 Genomes Project (sample NA12878, run SRR098401); the reference slices: UCSC (hg19); the genes: Ensembl (GRCh37); sequences: NCBI GenBank and UniProt; the yeast table: SGD, PaxDb, BioGRID, UniProt and AlphaFold DB; the structure 1MBN: RCSB PDB; the RNA-seq reads and yeast chromosome: nf-core/test-datasets (run SRR6357070); the airway counts: the Bioconductor package airway (Himes et al. 2014); the reads with adapters: nf-core/test-datasets (run SRR6357070); the tumour and normal reads and the truth set of somatic/: the SEQC2 consortium, cell lines HCC1395 and HCC1395BL (Fang et al. 2021, Nature Biotechnology), with the reference windows from UCSC (hg38); the reads of metagenomics/: a ZymoBIOMICS mock community sequenced by Nicholls et al. (2019, GigaScience; ENA run ERR2984773), with a database made from NCBI RefSeq and NCBI Taxonomy; the two bacterial windows of bacteria/: NCBI RefSeq (E. coli K-12 MG1655, Salmonella Typhimurium LT2); the files of hmmer/: the tutorial of HMMER 3.4 (with data of Pfam, Dfam and UniProt); the single-cell data of singlecell/: SRA run SRR8599150, as test files of kb_python and the BUStools getting_started release; the genotypes of plink2/: the 1000 Genomes Project, Phase 3 (The 1000 Genomes Project Consortium 2015, Nature), as the test file of PLINK 2, with synthetic files from PLINK 2's tests; the networks of networks/: STRING 12.5 (CC BY 4.0; Szklarczyk et al. 2025) for the genes of the airway experiment, and Zachary's karate club (Zachary 1977), as NetworkX has it; the ChIP-seq and ATAC-seq reads of chipseq/ and atacseq/: the test data of MACS (CTCF ChIP-seq of human chromosome 22; yeast ATAC-seq, SRA run SRR1822137, Schep et al. 2015), with MACS's own expected peaks. Details: /data/examples/README.md.
  • The Databases tab uses the public services of EMBL-EBI (UniProt, AlphaFold DB with Google DeepMind, InterPro, Ensembl, ENA, BLAST, QuickGO, OLS, Europe PMC), NCBI (E-utilities, PubChem), RCSB PDB, UCSC, STRING, Reactome, IntAct (EMBL-EBI), NDEx and g:Profiler (University of Tartu); the Networks tab uses STRING, IntAct, NDEx and g:Profiler too. Cite the databases you use in your work: each names the paper to cite on its web site.
