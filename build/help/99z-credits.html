Data and services

  • The example reads: the 1000 Genomes Project (sample NA12878, run SRR098401); the reference slices: UCSC (hg19); the genes: Ensembl (GRCh37); sequences: NCBI GenBank and UniProt; the yeast table: SGD, PaxDb, BioGRID, UniProt and AlphaFold DB; the structure 1MBN: RCSB PDB. Details: /data/examples/README.md.
  • The Databases tab uses the public services of EMBL-EBI (UniProt, AlphaFold DB with Google DeepMind, InterPro, Ensembl, ENA, BLAST, QuickGO, OLS, Europe PMC), NCBI (E-utilities, PubChem), RCSB PDB, UCSC, STRING and Reactome. Cite the databases you use in your work: each names the paper to cite on its web site.
