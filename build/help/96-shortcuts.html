Keyboard shortcuts

On a Mac, use ⌘ (Cmd) where it says Ctrl – except in the terminal: there Ctrl+C and Ctrl+L are the Ctrl key, as in the Mac's own Terminal (⌘+C copies).

Everywhere

Ctrl+\hide or show the help: the workbench fills the window
← → on the tab barthe next or previous tab
← → on the border between help and workbenchmake the help narrower or wider (or drag the border)
Escclose a dialog or menu

Help

Enter in the search boxopen the first result
↓ ↑move through the results
Escclear the search

Notebook – while editing a cell

Shift+Enterrun the cell, go to the next
Ctrl+Enterrun the cell, stay
Alt+Enterrun the cell, add a new one below
Ctrl+Ssave now
Ctrl+/comment or uncomment the lines
Tab / Shift+Tabindent / unindent
Escstop editing: the cell stays selected

Notebook – a selected cell

Enteredit it
A / Ba new cell above / below
M / Ymake it a text / code cell
D Ddelete it
↑ ↓ (or K J)the cell above / below

Terminal

↑ ↓earlier commands
Tabcomplete a command or file name
Ctrl+Cwhile a command runs: the program that is running finishes, the rest is skipped; a second time: the program is stopped by force (what it was writing is lost). At the prompt: clear the line
Ctrl+Lclear the screen
Home / Endstart / end of the line

To copy text from the terminal, select it with the mouse and press Ctrl+C – with text selected it copies instead of stopping.

Files

Ctrl+Ssave the file (files are not saved by themselves: a dot on the tab of a file marks changes that are not saved)
Ctrl+/comment or uncomment the lines
↑ ↓ Enter in the listmove through the files, open one
Shift+F10 in the listthe ⋯ menu of a file

3D viewer

Escclear the selection; stop measuring or box-selecting
Deleteremove the selected label or shape
↑ ↓ in the command lineearlier commands

Networks

The keys work once you have clicked the network.

Shift+click, Shift+dragadd to the selection; select the nodes inside a box
Double-click a nodezoom to it and its neighbours
Right-clickthe menu of a node, an edge or the background
Ctrl+Aselect every node
Escselect nothing
Deletedelete what is selected
Ctrl+Z, Ctrl+Shift+Z (or Ctrl+Y)undo, redo
Ffit the whole network in view
+ −zoom in, out (or the mouse wheel)
Enter in Find nodesselect the nodes found and zoom to them

IDE: RStudio

The full list is in RStudio’s Help ▸ Keyboard Shortcuts Help, and on the page RStudio.

Ctrl+Enterrun the current line, or the selected lines, in the Console
Ctrl+Shift+Ssource the whole script
Ctrl+Shift+Kknit or render the document
Ctrl+Alt+Iinsert a chunk into an R Markdown document
Esc in the Consolestop the command that is running

IDE: Spyder

The full list is in Spyder’s Help ▸ Keyboard shortcuts, and on the page Spyder.

F5run the whole file
Ctrl+Enter / Shift+Enterrun the current cell / run it and go to the next one
F9run the selected lines, or the current line
F12set or clear a breakpoint
Ctrl+F5debug the file; then Ctrl+F10 steps, Ctrl+F12 continues and Ctrl+Shift+F12 stops
Ctrl+Ishow the documentation of the name at the cursor
Ctrl+C in the consolestop the code that is running
