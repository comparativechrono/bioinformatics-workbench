Python

Python 3.13 (Pyodide), running in this page. NumPy, pandas and matplotlib load when Python starts; most other packages load the first time you import them, or with %pip install.

Packages

Pyodide's own packages load by themselves when a cell imports them – among them Biopython (import Bio), SciPy, scikit-learn, statsmodels, NetworkX, SymPy, Pillow, PyYAML and requests. Pure-Python packages from PyPI install with %pip:

%pip install seaborn
import seaborn as sns
sns.__version__

Installed packages last for this visit of the page: after a reload, run the %pip line again – keep it in the first cell of the notebook. Packages that need compiled code that has not been built for the browser cannot be installed; the error message says so.

Tables and plots

import pandas as pd
import matplotlib.pyplot as plt

genes = pd.read_csv("/data/examples/tables/yeast_genes.csv")
counts = genes.groupby("location")["essential"].mean().sort_values()
counts.plot.barh(figsize=(6, 4), xlabel="fraction of genes that are essential")
plt.tight_layout()
plt.show()

A DataFrame on the last line of a cell is shown as a table. Plots appear under the cell; plt.savefig("plot.png", dpi=150) also writes the picture as a file (in the notebook's folder).

Sequences with Biopython

from Bio import SeqIO
from Bio.SeqUtils import gc_fraction

for rec in SeqIO.parse("/data/examples/reads/reference.fa", "fasta"):
    print(rec.id, len(rec.seq), f"GC {gc_fraction(rec.seq):.1%}")

Your files

Python reads and writes your files: they are given to Python before each cell runs, and what it writes appears in the Files tab afterwards. The working folder is the notebook's folder (see Files and folders). /data/examples is read-only. Files larger than 300 MB are not passed to Python.

Data from the web

requests works with web services that allow requests from web pages – Ensembl, UniProt, NCBI E-utilities, EBI, the PDB and others (the Databases tab writes such code for you):

import requests

r = requests.get("https://rest.ensembl.org/lookup/symbol/homo_sapiens/CYP2C19",
                 headers={"Content-Type": "application/json"})
gene = r.json()
print(gene["id"], gene["seq_region_name"], gene["start"], gene["end"], gene["biotype"])

Sites that do not allow it (KEGG, most web pages) fail with a network error: download the file with your browser and upload it in the Files tab instead.

Python in the terminal

python script.py, python -c "…" and pip install NAME work in the terminal too, with the same Python as the notebooks (a script runs with its own variables). %run script.py runs a script inside a notebook.

Good to know

  • Python here runs on one processor core: no threads or multiprocessing, and no subprocess (use ! or %%bash for programs).
  • Memory is limited to a few gigabytes. Work on samples of very large files, or summarise them in the terminal first.
  • A long computation can be stopped with Stop; that restarts Python, so its variables are forgotten.
  • input() does not work in a notebook: put the values in a variable instead.
