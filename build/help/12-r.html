R

R 4.6 (webR), running in this page. Packages are downloaded the first time you load them; base graphics and ggplot2 plots appear under the cell.

Packages

library(NAME) downloads a package the first time it is used in a visit, from the builds of CRAN packages for the browser (repo.r-wasm.org) and of Bioconductor packages on r-universe. install.packages("NAME") works too, and so does BiocManager::install("NAME"). The first library(ggplot2) or library(dplyr) takes half a minute; packages last until the page is reloaded.

Tested in October 2026: ggplot2, dplyr, tidyr, readr, stringr, ape, seqinr, pheatmap, and from Bioconductor Biostrings, GenomicRanges, limma, DESeq2 and edgeR. Bioconductor packages come from its current release. DESeq2 and edgeR need the package locfit, which the repositories have not built for the browser: the workbench brings its own build of it, and R finds it there.

Differential expression: DESeq2 and edgeR

The example counts are a real RNA-seq experiment: four cell lines of airway smooth muscle, each with and without the steroid dexamethasone. The first library(DESeq2) downloads about 40 packages – a minute; DESeq() on 22,000 genes takes another.

library(DESeq2)
counts <- as.matrix(read.delim("/data/examples/rnaseq/airway_counts.tsv", row.names = 1, check.names = FALSE))
samples <- read.delim("/data/examples/rnaseq/airway_samples.tsv", row.names = 1)
samples$cell <- factor(samples$cell)
samples$dex <- factor(samples$dex, levels = c("untrt", "trt"))
dds <- DESeqDataSetFromMatrix(counts, samples, design = ~ cell + dex)
dds <- DESeq(dds[rowSums(counts(dds)) >= 10, ])
res <- results(dds, contrast = c("dex", "trt", "untrt"), alpha = 0.05)
summary(res)

The RNA-seq recipe goes further: plots, the top genes, the same with edgeR – and mapping RNA-seq reads with HISAT2 first.

A data frame on the last line of a cell is shown as a table. The plots of a cell appear after its printed output. ggsave("plot.png", width = 6, height = 4) or png("plot.png") … dev.off() also write the picture as a file.

Files

R reads and writes your files like Python does: the working folder is the notebook's folder (getwd()), ~ means /home/student, and /data/examples is read-only.

Programs and the terminal

system() cannot start programs in the browser: use a %%bash cell in the R notebook instead. In the terminal, Rscript script.R and Rscript -e '…' run R code with the same R; their plots go to Rplots.pdf unless the script opens a png() device.

Good to know

  • R cannot be interrupted in the middle of a computation: Stop restarts it (variables are forgotten).
  • Web requests from R (read.csv("https://…"), readLines(url)) work for services that allow requests from web pages; POST requests do not – use Python for those.
  • Downloaded R notebooks (.ipynb) run in Jupyter with the R kernel (IRkernel), and in Google Colab with the R runtime.
