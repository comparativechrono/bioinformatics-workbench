Variant calling

bcftools finds the positions where the reads differ from the reference, decides the genotypes, filters the calls and turns VCF files into tables. bgzip and tabix compress and index them.

The examples work in a folder of your own:

From a BAM file to variants

First a sorted BAM file (see Mapping reads):

minimap2 -ax sr -R '@RG\tID:NA12878\tSM:NA12878' /data/examples/reads/reference.fa \
    /data/examples/reads/NA12878_R1.fastq /data/examples/reads/NA12878_R2.fastq 2> /dev/null \
  | samtools sort -o mapped.bam -
samtools index mapped.bam

Then the two steps of bcftools: mpileup collects the evidence at each position, call decides the genotypes:

bcftools mpileup -f /data/examples/reads/reference.fa mapped.bam | bcftools call -mv -Oz -o calls.vcf.gz
bcftools index calls.vcf.gz
bcftools view -H calls.vcf.gz | cut -f 1-6 | head

-m is the multiallelic caller, -v keeps only variant sites, -Oz writes compressed VCF (-Ov plain VCF, -Ob BCF).

Filter and count

bcftools filter -i 'QUAL>=20 && INFO/DP>=5' -Oz -o filtered.vcf.gz calls.vcf.gz
bcftools index filtered.vcf.gz
bcftools view -H filtered.vcf.gz | wc -l
bcftools view -H -v snps filtered.vcf.gz | wc -l
bcftools view -H -v indels filtered.vcf.gz | wc -l
bcftools stats filtered.vcf.gz | grep -E "^SN|^TSTV"

The expression language: QUAL, INFO/DP, FORMAT/GT="1/1", TYPE="snp", with &&, ||. -e excludes instead of including.

A table of the calls

bcftools query -H -f '%CHROM\t%POS\t%REF\t%ALT\t%QUAL\t%INFO/DP[\t%GT]\n' filtered.vcf.gz > calls.tsv
head calls.tsv

A table like this reads straight into pandas or R (pd.read_csv("calls.tsv", sep="\t")). A known position, such as the CYP2C19*2 variant (rs4244285, G>A) at position 11,616 of human_CYP2C19 – NA12878 carries it on one chromosome (0/1):

bcftools view -H -r human_CYP2C19:11616 filtered.vcf.gz | cut -f 1-10

bgzip and tabix

A VCF file that tools read by region must be compressed with bgzip (not plain gzip) and indexed:

bcftools view filtered.vcf.gz > plain.vcf
bgzip -c plain.vcf > again.vcf.gz
tabix -p vcf again.vcf.gz
tabix again.vcf.gz human_CYP2C19:11000-12000 | cut -f 1-5

Also useful: bcftools norm (normalise indels against the reference), bcftools isec (compare two call sets), bcftools annotate. bcftools COMMAND --help lists the options of a command. The plugins (bcftools +NAME) cannot run in a browser.

igv filtered.vcf.gz mapped.bam shows the calls next to the reads in the Genome browser.
