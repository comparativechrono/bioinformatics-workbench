Reads to variants, in a notebook

A whole analysis in one notebook: check and trim the example reads, map them, call the variants, look at them in a table and a plot, ask Ensembl what they do – and keep every step, so the notebook is the record of the work.

The button writes the steps below into a new Python notebook in ~/notebooks; run its cells from the top. Or add the cells one by one with Add to notebook.

1. A folder for the work

The results go into a folder of their own. %cd makes it the folder of the notebook's code and of its %%bash cells.

import os
os.makedirs(os.path.expanduser("~/recipe-variants"), exist_ok=True)
%cd ~/recipe-variants

2. Check and trim the reads

fastp removes adapters, drops reads of poor quality, and reports on the reads before and after (it trims low-quality ends too when asked: --cut_tail). Its report, fastp.html, opens in the Files tab.

%%bash
fastp -i /data/examples/reads/NA12878_R1.fastq -I /data/examples/reads/NA12878_R2.fastq \
      -o trimmed_1.fastq -O trimmed_2.fastq -h fastp.html -j fastp.json 2> fastp.log
grep -A 4 "after filtering" fastp.log | head -10

3. Map them to the reference

The reads come from two regions of chromosome 10; reference.fa holds those two regions. -R names the sample in the BAM file, so that the VCF file names it too.

%%bash
minimap2 -ax sr -R '@RG\tID:NA12878\tSM:NA12878' /data/examples/reads/reference.fa \
         trimmed_1.fastq trimmed_2.fastq 2> minimap2.log | samtools sort -o mapped.bam -
samtools index mapped.bam
samtools flagstat mapped.bam

4. Call the variants

%%bash
bcftools mpileup -f /data/examples/reads/reference.fa -a AD,DP mapped.bam 2> /dev/null \
  | bcftools call -mv -Oz -o calls.vcf.gz
bcftools filter -i 'QUAL>=20 && INFO/DP>=5' -Oz -o filtered.vcf.gz calls.vcf.gz
bcftools index -t filtered.vcf.gz
echo "variants called: $(bcftools view -H calls.vcf.gz | wc -l), after filtering: $(bcftools view -H filtered.vcf.gz | wc -l)"

5. The variants as a table

bcftools query writes the fields you name as a table; pandas reads it.

%%bash
bcftools query -f '%CHROM\t%POS\t%REF\t%ALT\t%QUAL\t%INFO/DP[\t%GT]\n' filtered.vcf.gz > variants.tsv
head -3 variants.tsv
import pandas as pd

v = pd.read_csv("variants.tsv", sep="\t", names=["chrom", "pos", "ref", "alt", "qual", "depth", "genotype"])
v["type"] = ["SNP" if len(r) == 1 and len(a) == 1 else "indel" for r, a in zip(v.ref, v.alt)]
v.groupby(["chrom", "type", "genotype"]).size()

6. Quality and depth

Calls with few reads have low quality: the filter of step 4 removed the weakest.

import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(6, 3.5))
for gt, d in v.groupby("genotype"):
    ax.scatter(d.depth, d.qual, label=gt, s=20)
ax.set_xlabel("reads covering the position (DP)")
ax.set_ylabel("call quality (QUAL)")
ax.legend(title="genotype")
plt.tight_layout()
plt.savefig("quality_depth.png", dpi=150)
plt.show()

7. What do the variants do?

Ensembl's Variant Effect Predictor (VEP) says what each variant changes. The positions in the VCF file are on the two slices of the reference; on chromosome 10 of GRCh37 the slices start at 96,530,001 and 96,699,001, so the positions are moved before they are sent – to Ensembl's GRCh37 server.

import time
import requests

def post_json(url, data, tries=4):
    """POST data as JSON; when the service is busy or does not answer, wait and try again."""
    for attempt in range(tries):
        try:
            r = requests.post(url, json=data, headers={"Content-Type": "application/json", "Accept": "application/json"})
            if r.status_code not in (429, 500, 502, 503, 504):
                r.raise_for_status()
                return r.json()
        except requests.exceptions.ConnectionError:
            pass
        time.sleep(2 ** attempt)
    raise RuntimeError(f"no answer from {url} – try again in a few minutes")

start = {"human_CYP2C19": 96_530_000, "human_CYP2C9": 96_699_000}
lines = [f"10 {p + start[c]} . {r} {a} . . ." for c, p, r, a in zip(v.chrom, v.pos, v.ref, v.alt)]
answer = post_json("https://grch37.rest.ensembl.org/vep/homo_sapiens/region", {"variants": lines})
vep = pd.DataFrame([{"position (GRCh37)": x["input"].split()[1], "consequence": x["most_severe_consequence"],
                     "known as": ", ".join(c["id"] for c in x.get("colocated_variants", []) if c["id"].startswith("rs"))}
                    for x in answer])
vep

Position 96,541,616 is rs4244285, the CYP2C19*2 allele. VEP calls it a synonymous variant – the changed codon still codes for proline – yet it is the commonest reason for a CYP2C19 enzyme that does not work: the change creates a new splice site in exon 5, the mRNA is spliced wrongly, and no working enzyme is made. A prediction is not the whole story: read what is known about the variants that matter (Europe PMC, ClinVar in the Databases tab). NA12878 carries one copy (genotype 0/1); people with two copies turn the drug clopidogrel into its active form poorly.
